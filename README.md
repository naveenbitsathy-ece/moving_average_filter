# Moving average filter 

## 📌 Overview

This project implements an 8-Point Moving Average Filter (MAF) on a ZedBoard FPGA using Verilog HDL. A noisy analog signal is acquired through the PMOD AD2 (AD7991 ADC), filtered in real time inside the FPGA, and reconstructed using the PMOD DA2 DAC. The filtered output is observed on an oscilloscope to demonstrate noise reduction and waveform smoothing. The project showcases ADC interfacing, digital signal processing, DAC interfacing, and real-time FPGA implementation.
